项目开发约束

后续 AI Agent 参与开发时，应遵循以下约束：

1. 每次只实现一个明确的小目标，不要一次性生成整个系统。
2. 每次开启一个阶段之前，修改文件之前先检查已有文件、代码结构和构建方式。也不要在同一个阶段内反复检查，以节约token。
3. 不得在没有确认目标环境的情况下随意更换工具链。
4. 不得默认IMAX6ULL开发板支持所有桌面 Linux 软件包。
5. 优先使用成熟、轻量且维护良好的基础组件。
6. 每个阶段完成后必须运行并验证验收标准。
7. 修改或升级已有功能时，应尽可能保留已验证的行为。
8. 每次开发结束时，说明修改了什么，以及下一步应该做什么尽量简短明了。
9. 不要在用户尚未确认时直接进行大规模重构或添加大量新功能。
10. MQTT数据以软件模拟为主。
11. 当我说阶段完成时，创建并填写复现文档/阶段X/XXX.md
