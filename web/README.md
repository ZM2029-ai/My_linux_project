# web —— 网页管理端（运行在浏览器中）

阶段五实现。页面本身在浏览器里运行，数据来自网关提供的 HTTP REST API，**不直接访问数据库**。

## 计划结构

**一个功能一个页面/文件夹**，在实现时创建：

```
web/
├── index.html          # 设备列表总览
├── device/             # 设备详情与历史数据曲线
├── control/            # 远程控制入口（阶段六）
└── assets/             # CSS / JS / 图标
```

## 约定

1. 纯 HTML/CSS/JavaScript，**不引入需要构建的前端框架**（保持轻量，开发板侧只需提供静态文件）。
2. 所有数据通过网关的 HTTP API 获取，接口定义以 [`protocol/`](../protocol/README.md) 与阶段五设计为准。
3. 必须处理三种状态：**加载中**、**空数据**、**接口失败**，并在页面上给出明确提示。
4. 前端限制只是体验层，**权限校验必须在网关服务端做**（阶段六要求）。
