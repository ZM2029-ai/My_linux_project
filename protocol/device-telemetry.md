# 设备遥测与状态

主题中的设备 ID 是消息来源；载荷不重复存放设备 ID。时间采用北京时间（UTC+08:00），格式 `YYYY-MM-DD HH:MM:SS`。

遥测示例（温度单位为摄氏度，湿度单位为相对湿度百分比）：

```json
{"timestamp":"2026-11-02 12:00:00","temperature_c":25.3,"humidity_percent":55.1}
```

状态示例：

```json
{"timestamp":"2026-11-02 12:00:00","state":"online"}
```

`state` 为 `online` 或 `offline`。状态的时间表示该消息生成时间；特别是异常断线遗嘱在连接前生成，不代表实际断线时间。阶段四启用 SQLite 后，遥测保留设备采样时间和网关接收时间，设备状态变化按网关时间记录。

网关校验规则：载荷长度为 1～4096 字节，必须为 UTF-8 JSON 对象，不含 NUL 字节；JSON 嵌套深度不超过 8。时间必须是合法日期时间，年份范围为 1970～9999。遥测两个数值字段必须为有限数值，温度范围为 -100～200 摄氏度，湿度范围为 0～100。所有示例字段必填；额外字段可被忽略。遥测禁止保留消息。

网关内部另有 `unknown` 状态，表示当前无法确认设备是否在线，设备不发送此值。判断超时使用网关的单调时钟，不依赖设备时间戳，避免两端时钟偏差影响在线判定。
